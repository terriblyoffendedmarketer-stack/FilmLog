# Learnings & Gotchas

- Vercel 404 on all Flask routes | Vercel rewrite `/(.*)` rewrote `PATH_INFO` to destination path `/api/index` which Flask routes didn't match | Created `VercelPathMiddleware` in `app.py` and rewrote to `/api/index.py/$1` to cleanly restore original request path
- Enrich cycling between two films (Maidaan & Jawan) | `exclude_tmdb_id` only excluded the single immediate film, causing random pick between remaining 5-star films to bounce between the same two | Implemented session-level `seen_enrich` tracking plus persistent `enrichment_skips` table with 7-day cooldown
- Static CSS/assets 404 on Vercel | Vercel serverless Python container doesn't serve Flask static assets via CDN unless placed in root `public/` directory | Created `public/` and `public/static/` mirroring CSS, JS, manifest, and icons with zero CDN latency
- Query form hidden on Tonight | `{% if is_owner %}` guarded the entire query form, rendering the page as non-interactive past issues for any unauthenticated visitor | Made query bar always visible for everyone, with seamless inline owner password entry that authenticates and generates in one click
- Exposed password in UI | Hardcoded `8544` in tonight placeholder and error flash text | Replaced all UI references with generic `Owner password` and `Owner unlock` so credentials remain strictly private
- Drab robotic issue display | Separate stacked boxes (hero card, companion cards, raw markdown text box) caused duplicate content and zero visual variety | Created unified Sight & Sound Magazine Issue layout where the Hero gets primary real estate alongside its critique, followed by companion dispatches with their artwork and sells in a single cohesive article
- Hero recommendation text spilling on laptop | Nested padding in 660px container plus 240px rigid grid column squeezed text into ~250px | Widened layout to 780px and unified the essay into ONE continuous narrative using inline floating figures (hero 220px, companions 125px) allowing prose to breathe and flow with zero overflow
- Enrich 500 error | `db.get_enrichment_count()` called in `/enrich` routes was undefined in `filmlog/db.py` | Added `get_enrichment_count()` in `filmlog/db.py` returning un-annotated watched film count
- Weird star behavior | Individual `<label>` wrappers around radio inputs broke CSS sibling cascades so only 1 isolated star lit up, and `enrich_save` omitted the rating parameter | Implemented flex `row-reverse` `.interactive-star-rating` where hover and checked state highlight stars $1 \dots N$, and updated `enrich_save` to persist both ratings and notes
- Collapsed past issues & hero reading overlay | Viewing massive full-text articles directly on Tonight crowded the page and diluted anticipation | Created landscape 16:9 hero card with smooth CSS gradient mask teaser blur, collapsed past issue cards with poster thumbnails, and a centered cinema reading overlay lightbox pop-up (ESC / click to close)
- Missing backdrop & hero cover on Tonight | latest_issue.get("hero", {}).get("film") returned None because _parse_magazine_issue returns hero_film | Fixed access to latest_issue.get("hero_film") and added backdrop_url schema migration fetching 1280px TMDB backdrops
- Edge-to-edge Substack cover & Knowledge Graph | Right-floated hero figures squeezed essay text and static attribute lists felt flat | Implemented Substack full-width edge-to-edge landscape cover header, full-width companion breaks, borderless pull-quote epigraphs, and a 60fps interactive Taste Brain constellation canvas
- TMDB search disambiguation & fuzzy year matching | Generic single-word titles like "David" returned dozens of results with 8-result truncation hiding matches like 2013 | Created search_smart with URL regex detection, inline title+year extraction, and +-1/+-2 year fuzzy scoring window
- 5-star vs Hall of Fame coupling | 5-star rating was hardwired to Hall of Fame, confusing objective rating with emotional resonance | Added dedicated `hall_of_fame` boolean toggle in DB, UI partials, and routes, reserving Hall of Fame for emotional anchors
- Jellyfin generated comments in personal notes | 94 AI blurbs from Jellyfin synced into `personal_notes` polluted authentic handwritten reflections | Migrated all 94 entries into dedicated `jellyfin_notes` column and rendered in a separate "Notes from Jellyfin" section
- Rigid 7-day cooldown technical jargon | "Skip (7-day cooldown)" annoyed user and risked re-surfacing same skipped film after 7 days | Replaced with "Skip for now", deprioritized skips to a later pile with oldest-first recovery, and added taste relevance boost
- Portrait posters stretched in landscape containers | Films imported before `backdrop_url` column lacked 16:9 artwork and fell back to zoomed 2:3 posters | Backfilled 1280px TMDB widescreen backdrops, prevented fallback from stretching vertical posters, and implemented dual image architecture (Substack landscape cover at top + uncropped vertical poster cards inline in essay)
- High-friction journal creation | Journal required manual titles, manual tags, and searching for films to link | Made content the only required field; integrated Gemini to auto-generate punchy titles, auto-detect mentioned films via DB index, and auto-tag craft/genre themes
- Generated issues disappearing on Vercel | Vercel serverless /tmp resets on container recycling and auto_archive_issues(keep=2) actively hid older issues | Removed auto-archive keep limit, unarchived existing issues, and implemented bidirectional localStorage caching with `/api/issues/restore` background sync
- Explicit / vulgar quotes surfaced on Tonight | Random quote picker pulled from journals/notes without content moderation (e.g. Handmaiden erotic/sexual notes or incomplete sentence fragments) | Added strict sensitive/NSFW keyword blocklist, excluded explicit journal IDs, enforced self-contained complete grammatical clauses, and expanded curated cinephile fallback quotes
- Cropped portrait posters in editorial essay breaks | Small inline portrait cards inside essay broke reading immersion and cropped 2:3 posters into landscape boxes | Implemented widescreen multi-backdrop pipeline via TMDB `/images` (1280px landscape backdrops for cover and body breaks, with distinct secondary backdrop for hero film and clickable banners with overlaid titles)
- Repetitive headline phrasing ("The Architecture of...") | The recommendation prompt provided "The Architecture of..." as the primary example, biasing LLM headline generation | Added strict negative constraints against formulaic templates, mandated varied journalistic styles, and enforced a strict 3-film spread (1 Hero + 2 Companions) with prompt-aware candidate keyword scoring
- Cold start onboarding definition | Spec initially suggested Criterion/arthouse films for onboarding starter pack, risking boring snoozefests that alienate users | Redefined starter pack to 30 popular, engaging, widely-loved modern cornerstones (min 5 selections) with an instant bridge to cherry-pick from Prashil's Hall of Fame and watchlist
- Milestone fatigue & level inflation | Incrementing titles every 5 notes felt arbitrary and diluted rank weight, while single entries lacked tangible reward | Rebuilt into 15 major tiers (15 signals each) with 3 metallic subgroups (Bronze/Silver/Gold every 5 signals), illuminated 5-pip diode gauge, clean signal stats, and a Pokémon-style Vault Badge Case
- Session loss on Vercel & mobile lock stuck | os.urandom(32).hex() secret key broke session cookies across serverless instances and HTMX partial swap left lock text on screen | Generated deterministic SHA-256 secret seed from password, added X-Owner-Password localStorage auto-attachment, and hid lock elements on successful unlock
- Serverless timeout & stuck recommendation button | Recommendation generation took 12-15s, exceeding Vercel 10s default limit causing 504 Gateway Timeout without HTMX error handler | Added maxDuration: 30 in vercel.json, consolidated _has_ai(), added htmx:responseError fallback to reset button, and hid stale initial hero card on fresh load
- Mobile badge accordion clutter pushing micro-enrich below fold | Accordion required extra taps and vertical height pushed review card below the fold on phones | Replaced accordion with desktop 2-column sticky right-rail and mobile single-line ribbon (<60px) showing only conquered badges up to current level
- Clunky markdown text dumps in linked recommendations & dead archive links | Film detail dumped raw issue markdown without link or parsing, and Tonight displayed an archive link without archive controls | Replaced with parsed clickable editorial link cards (?issue=id lightbox auto-open), 3-item accordion for overflow, archived issue exclusion, and owner archive action
- Signal widget centered above film on Enrich & Tonight rail distracting at top | Enrich had 420px container placing badges on top of movie poster, and Tonight rail started at page top level with hero query | Converted Enrich to desktop 2-column with poster/notes front-and-center (badges on sticky right rail, mobile ribbon below card), and postponed Tonight side rail to start cleanly after the quote
- User stuck on expired or missing AI API key | No in-app UI existed to update or override the server Gemini API key when quota exhausted or key expired, and owner mode ignored custom keys | Added minimal navbar key icon (.nav-key-btn with green active status dot), quick Tonight key button, and universal AI API Key modal with live /api/test-key validation, attaching X-Gemini-Key to all requests for both owner and guest modes

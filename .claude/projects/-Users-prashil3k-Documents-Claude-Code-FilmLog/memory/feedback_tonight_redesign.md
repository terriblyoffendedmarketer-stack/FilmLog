The Tonight page questionnaire doesn't work. Remove or completely rethink it.

**Why:** Prashil never decides based on genre, ending preference, or attention level. "Half watching" is never a real state — he's always fully engaged. Asking about cognitive load creates a trap (he'd always pick low, defeating the purpose). Nobody sits down and decides "I want an open ending tonight." These questions produce the same inputs repeatedly and narrow recommendations instead of expanding them.

**How to apply:**
- Remove the half-watching, ending preference, and mood/energy questions
- The only potentially useful question: "who's watching" (solo vs with someone)
- If no good variable question exists, skip questions entirely
- Instead: pull from taste profile + recent watches, suggest diverse picks across different vibes
- Consider surfacing a data point from the journal or taste model as a conversation starter ("you wrote about X — here's something that connects")
- The goal is variety and surprise, not narrowing down to a safe pick

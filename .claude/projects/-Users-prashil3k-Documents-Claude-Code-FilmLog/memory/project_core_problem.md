The core problem is the gap between "want to watch" and "actually watching."

**The masterpiece avoidance trap:** Films like Schindler's List get mentally categorized as "need to be in the right mindframe" — but that mindframe never arrives. The film sits on a list forever. The tool must not reinforce this by grouping films by prestige/difficulty. It should find the bridge: "yes this is a great film, but here's why it actually works for tonight."

**Mood-realistic matching:** Prashil is often tired after a day. He wants something easygoing and fun — but never mindless. That's a narrow band that's very hard to search for manually. Netflix's infinite choice makes it worse. The tool needs to match to who he actually is right now, not an idealized future version of himself.

**The Mubi trap:** Had a Mubi subscription for 2 years, watched 2 films total. The problem isn't access to niche cinema — it's the bridge between having it available and actually pressing play. The "sell me this film" editorial is the bridge.

**The Netflix paralysis:** Too many options = watch nothing. Filmlog's answer is 2-3 films max, with specific reasons why tonight.

**Fun but not mindless:** This is Prashil's most common viewing state. He can never watch something truly mindless — it feels like a waste of time. But he also doesn't always want cognitive load. The sweet spot is engaging-but-accessible. The recommendation engine needs to understand this gradient, not just genre.

**Why:** Every recommendation, every UI decision, every filter should be measured against: "does this make it more likely he actually watches something tonight?"

**How to apply:** Never group films by prestige/difficulty. Never make "masterpiece" a category. The sell should always normalize watching great films on a Tuesday night. The mood calibration should detect the tired-but-not-mindless state and have films ready for it.
